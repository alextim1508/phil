# phil

Проект использует Java 25, Gradle, Spring Boot и Spring AI.

Для работы приложения нужна Ollama с настроенной моделью; параметры подключения указаны в `application.yaml`.

Текущий сценарий — урок 9: расследование по материалам в `incident/` и сканам в `scans/`.
Запускайте `.\gradlew.bat bootRun` из корня проекта. Приложение выполняет несколько
реплик в одном разговоре, очищает старые результаты инструментов и сжимает историю
при достижении 40% окна контекста. Последние пять результатов сохраняются.

Быстрые тесты: `.\gradlew.bat test`.
